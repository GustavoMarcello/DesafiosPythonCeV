## 📌 Sobre o projeto

Este repositório reúne os **enunciados dos desafios de Python** que acompanham meus estudos baseados no conteúdo do **Curso em Vídeo**, do professor Gustavo Guanabara.

A ideia é simples: abrir um exercício, entender o problema e tentar chegar à solução sem olhar código pronto.

Por isso, aqui os arquivos funcionam como uma coleção de desafios organizada por etapas de aprendizado.

> Terminou um exercício e quer comparar abordagens?  
> As minhas soluções estão em **[DesafiosResolvidosPythonCeV](https://github.com/GustavoMarcello/DesafiosResolvidosPythonCeV)**.

## 🚀 Como usar

Clone o repositório:

```bash
git clone https://github.com/GustavoMarcello/DesafiosPythonCeV.git
```

Entre na pasta:

```bash
cd DesafiosPythonCeV
```

Escolha um exercício, por exemplo:

```text
mundo1/d1.py
```

Abra o arquivo no seu editor favorito, leia o enunciado e implemente sua solução abaixo dele.

Exemplo:

```python
"""
EXERCÍCIO D1 - Olá Mundo!
Crie um programa que:
1. escreva a mensagem "Olá, Mundo!" na tela
"""

# sua solução começa aqui 👇
```

## 💡 Sugestão de estudo

Uma forma simples de aproveitar melhor o repositório:

1. leia o enunciado e tente resolver sozinho;
2. teste entradas diferentes e casos extremos;
3. refatore a solução buscando clareza;
4. compare com outras implementações apenas depois;
5. volte ao exercício algum tempo depois e tente resolvê-lo novamente.

O objetivo não é apenas fazer o código funcionar, mas desenvolver **raciocínio, autonomia e repertório de soluções**.
